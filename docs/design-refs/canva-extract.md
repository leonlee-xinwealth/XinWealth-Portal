## 调色板（从 10 页 PNG 采样，非目测）

| 角色 | Hex | 用在哪 |
|---|---|---|
| 主蓝 | `#002F80` | 标题、表格分组条、封底底色、数字 |
| 强调琥珀 | `#FEBA3A` | 章节号方块、标题下短横、金额高亮条、图标底 |
| 面板灰 | `#EDEDED` | 引言panel、小计行、说明卡 |
| 炭灰 | `#4F4F4F` | 正文、合计行底色（白字） |
| 白 | `#FFFFFF` | 纸底 |

对照 XinWealth 现有品牌色：navy `#0A2540`、gold `#C8A97E`。**角色相同，温度不同** —— Canva 这套更亮更"企业年报"，XinWealth 那套更深更"私人财富"。

## 版面系统（可直接搬）

**页面家具**
- 琥珀实心方块 + 白色章节号（`01`…`08`），压在照片边缘或标题左侧
- 特粗无衬线导航蓝大标题，可换行
- 标题下一道短琥珀横线（约 90×6px）
- 页脚：细横线 + 一侧圆形底页码 + 另一侧斜体 running title；**左右页交替方向**（p06 页码在左，p07 在右）

**表格语法（p06 / p07 — 本模板最有价值的部分）**
- 琥珀底条承载头号数字（`Revenue : $1000.000`）
- 导航蓝满宽分组条，白色粗体（`Cost of Sales`）
- 明细行：左标签、右数字，均为导航蓝
- 小计行：浅灰底 `#EDEDED`，粗体
- 合计行：炭灰底 `#4F4F4F`，白色粗体
- 负数用括号 `(30.000)` 且加粗变蓝
- 标签列与数字列之间一道细竖线
- 底部 `Notes:` 斜体小字

**其他可复用件**
- 灰底编号要点 panel（p02）→ 执行摘要看板
- 琥珀菱形 + 虚线竖轴的时间线（p04）→ 复盘周期 / 目标时间轴
- 大引号 + 灰底竖排引言块（p04）→ 顾问点评
- 琥珀/导航蓝交替胶囊标签 + 短横 + 灰底说明卡（p08）→ 「发现 → 后果」配对
- 封底（p10）：满版导航蓝 + 居中白 logo + 底部浅灰联系带，三列各带琥珀圆形图标挂在细蓝竖线上 → 直接可用于 P29

## 两个必须注意的落差

**1. 模板里一张真图表都没有。** p04 / p06 / p07 / p08 / p09 里看起来像图表的东西**全部是商业图库照片**（有人在看图表的照片）。所以我需要的 13 个可视化组件（折线、仪表盘、环形、雷达、瀑布、双环对比、流程图……）在这个模板里没有任何参照，得自己定。

**2. 模板大量依赖商业图库照片。** 封面、章节页、内容页都有大幅摆拍照片。这份 CFP 报告是给具名 VIP 客户的私人财务规划，塞图库照片会显得廉价，而且我们没有任何有授权的图片资源。建议把照片位一律换成数据可视化或留白。

## 结构对照（模板 10 页 vs 我们的 29 页）

| 模板 | 我们对应 |
|---|---|
| p01 封面 | P1 封面 |
| p02 Executive Summary | P4 执行摘要 |
| p04 Management Discussion | P13 SWOT / 各模块建议页 |
| p06 Income Statement | P7 现金流明细 |
| p07 Cash Flow Statement | P9-10 资产负债明细 |
| p08 Notes（胶囊+说明卡） | P15 / P18 发现与后果 |
| p09 Auditor's Report | P3 免责声明 |
| p10 封底 | P29 封底 |

模板没有覆盖到的：目录、财务比率诊断、保险、传承、投资适宜性、退休推演、税务、专项目标 —— 也就是我们 29 页里的大多数。**这个模板给的是版面语法，不是页面清单。**
