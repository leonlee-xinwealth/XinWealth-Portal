## 落定的方向

**XinWealth 品牌色 + Canva 模板的版面语法。**

配色（品牌色胜出，不采用 Canva 的 #002F80/#FEBA3A）：
- 主色 navy `#0A2540`
- 强调 gold `#C8A97E`
- 与 Portal 前端、保险报告、suitability 报告共用同一套 `pdf/insuranceReport/theme.ts` 基线，
  保证客户并排看几份文件时是一家人

从 Canva 模板搬过来的结构：
- 章节号实心方块（金色底白字）+ 特粗导航蓝标题 + 标题下短金横线
- 表格分层：金色底条放头号数字 → 导航蓝满宽分组条 → 明细行 → 浅灰小计 → 深底白字合计，负数括号加粗
- 页脚：细横线 + 圆形底页码 + 斜体 running title，左右页交替方向
- 封底：满版导航蓝 + 居中 logo + 底部浅灰三列联系带
- 灰底编号要点 panel（执行摘要看板）、胶囊标签 + 说明卡配对（发现→后果）

从方向 A/C 保留的：
- 象牙纸底 `#FBF9F4` 与金色发丝线（A）
- 衬线字承担标题与数字，无衬线承担正文标签（A）
- 每页顶部的深色页眉带作为全书识别系统（C）

不采用：
- Canva 的商业图库摆拍照片 —— 私人财务规划报告放图库照片掉价，且模板里所有「图表」其实都是照片。
  照片位一律换成真实数据可视化或留白；确有需要时按用户授权从 Canva 取图。
- C 版引言块的左侧竖条（侧边彩条是典型模板感）

## 未决

- **logo 仍未提供。** 封面与封底当前使用衬线文字标 `XinWealth` 作为诚实占位，待用户提供 PNG（透明底，宽 ≥900px）或 SVG 后替换。
- 模板只覆盖 29 页中的 8 页；其余版面（目录、七大比率、保险、传承、投资适宜性、退休推演、税务、目标）无参照，由本项目自行确定。
