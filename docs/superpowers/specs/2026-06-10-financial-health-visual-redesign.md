# Financial Health Check — 视觉化重设计规格

**日期：** 2026-06-10  
**组件：** `components/FinancialHealthCheck.tsx`  
**状态：** 待实现

---

## 一、背景与目标

现有 `FinancialHealthCheck` 组件以密集表格呈现 9 项财务指标（5 列文字），信息量大但难以快速消化。目标是在保留全部数据的前提下，通过视觉化让客户一眼看懂自己的财务状况。

---

## 二、设计方案：B+C 混搭

### 整体布局（三层）

```
┌─────────────────────────────────────────────────────┐
│  顶部：总分 Banner（环形图 + 4 类迷你进度条）           │
├──────────────┬──────────────────────────────────────┤
│  左：雷达图   │  右：4 个类别卡片（指标横向进度条）      │
│  (220px)     │                                      │
└──────────────┴──────────────────────────────────────┘
```

---

## 三、各区块详细规格

### 3.1 顶部 Score Banner

- 深蓝渐变背景（`#1e3a5f → #1d4ed8`），圆角 20px
- **左侧**：环形仪表盘，显示总分（0–100 整数），金色描边填充
- **右侧**：
  - 大标题 "Financial Health Check"
  - 副标题：一句话概括当前状态（根据总分动态生成，见下方文案规则）
  - 4 行迷你进度条（流动性 / 债务 / 保障 / 积累），白色半透明底

**总分副标题文案规则：**
| 总分范围 | 文案 |
|---------|------|
| ≥ 80    | 财务状况优秀，继续保持 |
| 60–79   | 整体状况良好，有提升空间 |
| 40–59   | 存在明显薄弱环节，建议优先改善 |
| < 40    | 财务风险较高，需立即关注 |

---

### 3.2 左侧雷达图

- 4 轴正方形雷达（N=流动性、E=债务、S=积累、W=保障）
- 数据多边形：蓝色填充（`rgba(37,99,235,0.12)`），蓝色描边
- 各顶点彩色圆点，颜色对应类别分数色（绿/黄/橙/红）
- 图下方图例：4 行 `● 类别名 — XX%，文字说明`
- 不可交互，纯展示

---

### 3.3 右侧类别卡片

每个类别一张白色卡片，内部结构：

```
[类别 emoji + 名称]              [类别分 XX/100，彩色徽章]
[类别进度条，颜色对应分数]
[指标列表，每行：]
  指标名称中英文  |  横向进度条（带基准刻度线）  |  数值  |  状态徽章
```

**布局：**
- 流动性（2 项指标）— 独立一行，宽 100%
- 债务管理（3 项指标）— 独立一行，宽 100%
- 风险保障（1 项）+ 财富积累（3 项）— 并排 `grid 1fr 1fr`

**指标进度条：**
- 宽度 = 指标数值相对于满分量程的百分比（各指标量程见下方）
- 基准刻度线 = 灰色竖线，标注"达标线"位置
- 颜色：绿（健康）/ 黄（警告）/ 红（危险），与现有 `getStatus()` 逻辑一致

**各指标量程（用于进度条宽度换算）：**
| 指标 | 满量程（100% 宽） |
|------|----------------|
| basicLiquidityRatio | 12 个月 |
| liquidAssetToNetWorth | 40% |
| solvencyRatio | 100% |
| debtServiceRatio | 70% |
| nonMortgageDSR | 40% |
| lifeInsuranceCoverage | 20 倍 |
| savingsRatio | 50% |
| investAssetsToNetWorth | 100% |
| passiveIncomeCoverage | 150% |

**状态徽章：** 与现有一致（绿/黄/红，中文标签），保留 `!` 信息按钮，点击打开现有 `InfoModal`

## 四、评分逻辑

### 指标评分（3 档）

| 状态 | 分数 |
|------|------|
| 健康/优秀/理想 | 100 |
| 正常/可接受/不足/偏低/安全/资金闲置/需提升 | 60 |
| 危险/较差/风险大 | 20 |

评分复用现有 `getStatus()` 函数——`color === 'text-green-500'` → 100，`text-yellow-500` → 60，`text-red-500` → 20。

### 类别评分

类别内各指标分数简单平均（等权重）：

- **流动性** = avg(basicLiquidityRatio, liquidAssetToNetWorth)
- **债务管理** = avg(solvencyRatio, debtServiceRatio, nonMortgageDSR)
- **风险保障** = lifeInsuranceCoverage
- **财富积累** = avg(savingsRatio, investAssetsToNetWorth, passiveIncomeCoverage)

### 总分

```
总分 = round((流动性 + 债务管理 + 风险保障 + 财富积累) / 4)
```

4 个类别等权重（各 25%）。

## 五、响应式处理

- **≥ 1024px**：雷达图 + 类别卡片左右并排（现有布局）
- **< 1024px**：雷达图隐藏，类别卡片全宽堆叠，顶部 Banner 改为纵向排列
